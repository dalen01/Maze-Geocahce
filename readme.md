## Arduino Code for "Keep Talking and Nobody Explodes (Maze)" Geocache

This is an Arduino code that uses buttons and a LED matrix to create a geocache based on the game "Keep Talking and Nobody Explodes".
It also uses LEDs to indicate when the player completes the levels and a solenoid to release the cache log.

# Equipment list:
* Arduino Nano (Or similar device/same footprint)
* PCB (with components)
* 3xAA battery pack
* solenoid based lock
* Arcade joystick
* Wires
